## 1. Who is this for? (Не абстрактно — конкретный человек)

**Первичный пользователь: Сергей (OrangeHat founder)** — запускает и управляет 10+ проектами, использует Jcode каждый день для разработки. Сейчас вынужден открывать терминал и заходить в Jcode руками. Хочет иметь агента, который доступен 24/7 через Telegram, помнит контекст между проектами, и может выполнять рутинные задачи без участия человека.

**Вторичный: другие разработчики OrangeHat** — те же проблемы, плюс хотят общего агента для координации команды.

**Третичный: клиенты OrangeHat** — потенциально могут получить managed agent как сервис (SaaS-модель: хостим агента для клиентов).

## 3. Why now? (Что изменилось?)

1. **Hermes Agent открыт и документирован.** Архитектура, паттерны, алгоритмы — всё можно изучить и адаптировать. Не надо изобретать с нуля.

3. **OrangeHat экосистема растёт.** 10+ проектов, нужна автоматизация координации.

4. **Рынок валидирован.** Hermes — 209k звёзд, OpenClaw — 347k. Спрос на personal AI agents огромный.

5. **Риск опоздать.** Если не сделать сейчас, через 6 месяцев будем догонять.

## 4. What's the 10-star version? (Unlimited resources)

ohAgent как **операционная система для AI-агентов OrangeHat**:

- **24/7 Daemon:** Живёт на K8s кластере, масштабируется горизонтально
- **Все каналы:** Telegram, Discord, Slack, WhatsApp, Email, Web UI, голосовые звонки
- **Глубокая память:** Помнит всё обо всех проектах, людях, решениях. Compounding knowledge base.
- **Self-learning:** Создаёт и улучшает skills. Через месяц работы знает твои паттерны лучше, чем ты сам.
- **Multi-agent orchestration:** Один "шеф-агент" распределяет задачи между специализированными sub-агентами (dev, devops, accounting, legal, marketing)
- **Proactive intelligence:** Сам замечает проблемы и предлагает решения. "Серёж, сертификат на orangehat.eu истекает через 3 дня, обновить?"
- **Full OAuth integration:** Подключен ко всем сервисам (Gmail, GitHub, Cloudflare, банки, CRM)
- **Desktop + Mobile:** Управляет компом, запускает приложения, делает скриншоты
- **Voice interface:** Голосовые команды, транскрибация встреч
- **Managed SaaS:** Клиенты OrangeHat могут арендовать своего ohAgent

## 5. What's the MVP? (Smallest thing that proves the thesis)

**MVP = Фазы 1-2:**
- Jcode-daemon (24/7 работа)
- Profile System (изоляция per-user/per-project)
- Telegram Gateway (один канал, самый важный)
- SQLite + FTS5 session storage (searchable history)

**Критерий успеха MVP:**
> Сергей отправляет сообщение в Telegram `@ohAgentBot` → агент выполняет задачу в репозитории → отвечает результатом. Задача может выполняться фоном (daemon не закрывается).

**Time to MVP:** 5-9 недель (Rust-разработка)

**v1.0 = Фазы 1-4 (реальный продукт):**
- + глубокая память (pgvector)
- + self-learning skills
- + Autonomous Curator
- + Cron scheduler

**Критерий успеха v1.0:**
> Через месяц использования ohAgent создал 5+ skills, помнит контекст 3+ проектов, выполняет рутинные задачи по расписанию, пользователь не открывает терминал для большинства задач.

## 8. Competitive landscape (Что уже есть)

| Конкурент | Сильные стороны | Слабые стороны | Почему мы всё равно делаем |
|---|---|---|---|
| **Hermes Agent** | Self-learning, 209k звёзд, MIT | Python, нет deep Rust интеграции | Мы строим на Rust + Jcode, глубже интегрировано с нашими проектами |
| **OpenClaw** | 347k звёзд, 24+ платформ | Катастрофа безопасности (900+ malicious skills) | Мы строим безопасно с нуля |
| **TrustClaw** | OAuth-only, 20k+ tools | Managed cloud, нет self-hosting контроля | Мы self-hosted, полный контроль |
| **Claude Cowork** | Desktop automation | macOS only, закрытый исходный код | Мы open source, кроссплатформенные |

**Наше уникальное преимущество (moat):**
- **Jcode как ядро** — лучший coding agent на Rust с полноценным swarm
- **Глубокая интеграция с экосистемой OrangeHat** — все проекты, K8s, Vault, PostgreSQL уже настроены
- **Open source + self-hosted** — полный контроль, нет vendor lock-in
- **Безопасность с нуля** — учимся на ошибках OpenClaw, изолируем sensitive операции

## 9. Архитектурные решения (предварительно)

| Решение | Обоснование |
|---|---|
| **Rust (не Python)** | Jcode на Rust, экосистема OrangeHat на Rust/Go. Производительность, безопасность типов, нет GIL. |
| **Sidecar для AI-heavy** | Skill creation/curator могут быть на Python, соединены через MCP |
| **PostgreSQL + pgvector** | Уже есть в K8s кластере, не плодим новые БД |
| **DragonflyDB для rate limiting** | Уже есть в K8s, идеально для gateway |
| **HashiCorp Vault** | Уже обязательно по архитектурным правилам OrangeHat |
| **Telegram first** | Самый важный канал для Сергея, минимальная сложность интеграции |
| **OpenTelemetry** | Tracing и метрики с первого дня (уже в кластере) |

## 10. Риски

| Риск | Вероятность | Влияние | Mitigation |
|---|---|---|---|
| Rust разработка медленнее Python | Высокая | Среднее | Python sidecar для AI-heavy, Rust для ядра |
| Jcode API нестабилен (нет публичного API) | Средняя | Высокое | Обсуждаем с командой Jcode, используем MCP/selfdev |
| Сложность Gateway (20 адаптеров) | Средняя | Среднее | Только Telegram на MVP, остальные позже |
| Memory engine сложен | Средняя | Среднее | Начинаем с SQLite+FTS5, pgvector потом |
| Self-learning "explosion of skills" | Средняя | Низкое | Curator с первого дня, pruning by default |
| Есть ли спрос за пределами Сергея? | Низкая | Низкое | Пока не важно — внутренний инструмент |

## 12. Go/No-Go Recommendation

### ✅ GO — строим.

**Аргументы:**
1. Боль реальная (8/10), quantified
2. Рынок валидирован (Hermes 209k звёзд)
3. Технический фундамент готов (Jcode + K8s + Vault + PG)
4. MVP scope реалистичный (5-9 недель)
5. Финансовые риски минимальны (~$0 дополнительных затрат)
6. Strategic fit с экосистемой OrangeHat

**Conditions:**
- Начинаем с MVP (фазы 1-2), не распыляемся
- Jcode-daemon + Telegram gateway — проверяем viability
- Если через 3 недели нет работающего daemon → пересматриваем
